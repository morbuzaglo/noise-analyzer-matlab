# ISO 9613-2:2024 — what changed vs. the 1996 edition (full review, 2026-09-14)

Source: `standard_iso_9613-2_2024_page-0001.pdf` (BS ISO 9613-2:2024, 56 pp., no longer DRM-locked
— see note at bottom). Covers clauses 6-9 and Annexes A-D in full (every numbered equation read
directly off the page images and transcribed, not OCR'd — OCR failed on the math throughout this
document, same as the 1996 scan). Not fully ported into `matlab/+noiseanalyzer/` — see each
section below for what's implemented vs. notes-only.

## Clause 7.3 Ground attenuation — formula for combining As/Ar/Am changed

Table 3 itself (the As/Ar/Am per-band expressions, and the a'/b'/c'/d' curve-fit functions) is
**byte-for-byte identical** to 1996. What changed is how they combine into the final Agr:

- 1996: `Agr = As + Ar + Am` (plain sum, eq.9).
- 2024: a new non-linear combination —
  - `G(region) = sum(Gn*dn)/sum(dn)` (eq.10) — new: lets a region's ground factor be a
    length-weighted average of sub-sections with different G, rather than one G per region.
  - `Agr = -10*lg[1 + (10^(-A'gr/10) - 1)*Kgeo]` dB (eq.11)
  - `A'gr = As + Ar + Am` (eq.12) — the old 1996 sum, now just an intermediate quantity.
  - `Kgeo = [dp² + (hS-hR)²] / [dp² + (hS+hR)²]` (eq.13) — a new geometric correction factor.
  - Purpose per the standard's own note: eq.11 "accounts for the vanishing ground influence if
    dp < hS and/or dp < hR" — i.e. fixes a 1996 edge case where the simple sum could over-predict
    ground attenuation at short range / large height differences.
- The A-weighted-only **simplified method** (1996 eq.10) is **unchanged**: 2024 eq.14 is the same
  `Agr = 4.8 - (2*hm/d)*(17+300/d) >= 0`.
- The ground-reflection directivity term also got folded into Kgeo: 2024 `D_omega = 10*lg(1+Kgeo)`
  (eq.15) is algebraically identical to 1996's `D_omega = 10*lg{1 + [dp²+(hS-hR)²]/[dp²+(hS+hR)²]}`
  — same formula, just factored to reuse Kgeo, not a substantive change.

## Clause 7.4 Screening — barrier diffraction formula substantively reworked

- Split into an explicit condition on Agr: eq.16 `Abar = Dz - Agr > 0` applies when `Agr > 0`;
  eq.17 `Abar = Dz > 0` applies for lateral (vertical-edge) diffraction **or whenever Agr < 0**
  (1996 only split on top-edge vs. lateral, not on the sign of Agr — consistent with Agr now being
  able to go negative under the new eq.11 above).
- **Dz formula itself changed**, not just relabeled:
  - 2024: `Dz = 10*lg[1 + (2 + C2/lambda)*C3*z*Kmet]` dB for `z > zmin` (eq.18); `Dz = 0` for
    `z <= zmin` (new floor, replacing 1996's simple `z <= 0` threshold).
  - 1996: `Dz = 10*lg[3 + (C2/lambda)*C3*z*Kmet]` — no zmin concept at all.
  - New: `zmin = -2*lambda/(C2*C3)` (eq.19).
  - `C3` for multi-diffraction: `C3 = [1+(5*lambda/e)²] / [(1/3)+(5*lambda/e)²]` (eq.20) — same
    formula as 1996's double-diffraction C3, but now `e` generalizes to "the length of the ray
    path between the first diffracting edge behind the source and the last diffracting edge in
    front of the receiver" for **any number of edges** (1996 only handled up to 2 edges/double
    diffraction).
  - `Kmet` formula changed to handle multiple edges (eq.21, bracket extent confirmed against a
    300dpi crop — the square root spans the entire expression):
    `Kmet = exp{ -(1/2000) * sqrt( [max(dSS,dSR)+e] * min(dSS,dSR) * d / [2*(z-zmin)] ) }`,
    vs. 1996's plain `exp[-(1/2000)*sqrt(dss*dsr*d/(2z))]`.
### 7.4.1 continued — path-length-difference formulas for multiple edges

- Eq.(22) (default/general method, straight "rubber-band" ray path over the top, Figure 9):
  `z = (dSS + dSR + e) - d` — note this is **linear**, no sqrt/`a²` term, unlike what's in
  `barrierAttenuation.m` currently. Here dSS/dSR/e are true 3D ray-path segment lengths along the
  rubber-band polygon (constructed source→edge1→edge2→...→edgeN→receiver), so the geometry is
  fully captured without a separate lateral term.
- Eq.(23): `z = max(zn)` — for an *unblocked* line of sight that still grazes past one or more
  edges, take the largest (least negative) of the per-edge z values (each computed via eq.22 with
  e=0 for that edge alone) as the controlling value.
- **7.4.2 Alternative method** (for one edge, or barrier edges not perpendicular to the S-R line
  in plan view / sloping / bent — Figure 10): project source, receiver and edge(s) onto a plane
  perpendicular to the edges; find the relevant edges via a rubber-band polygon in that
  projection; then eq.(24): `z = sqrt[(dSS+dSR+e)² + a²] - d`, where here dSS/dSR are
  *perpendicular point-to-edge* distances (not ray-path segments) and `a` is the S-R separation
  component parallel to the barrier edge. **This eq.(24) form is what `barrierAttenuation.m`
  currently implements** — i.e. the current code implements the 7.4.2 alternative method, not the
  7.4.1 default method (eq.22/23). Both are valid per the standard; eq.24 was carried over
  unchanged from the 1996 single/double-diffraction formula (1996 eq.16/17), which is presumably
  why it was implemented first. Not yet reconciled — could add eq.22/23 as an alternative/
  additional z-calculation path.

### 7.4.3 Lateral diffraction around vertical edges

Analogous rubber-band construction but in a *lateral* plane (perpendicular to the vertical S-R
plane) — up to two lateral paths (left/right around the obstacle group), each producing its own
`Abar,side1`/`Abar,side2` via the same Dz formula (eq.18) applied to that path's z. A lateral path
is neglected if the maximal distance of its supporting points from the direct S-R line exceeds the
vertical-plane supporting points' maximal distance by more than a factor of 8. Lateral diffraction
is not considered at all if elevated ground contributes to the over-the-top ray path. z values from
lateral construction are always positive by construction (no negative-z / z≤zmin case for these).

### 7.4.4 Combining vertical and lateral diffractions, and limitations — resolves the cap question

- Eq.(25): `Abar = -10*lg(10^(-0.1*Abar,top) + 10^(-0.1*Abar,side1) + 10^(-0.1*Abar,side2))` dB —
  energetic combination of the top-edge and up to two lateral-diffraction contributions. If a path
  isn't relevant, its summand is 0. If the result is negative, effective Abar = 0.
- **The 1996-era caps are confirmed to still apply in 2024**, resolving the open question from the
  first update: *"For diffraction over the top in the vertical plane the barrier attenuation Dz,
  in any octave band, should not be taken to be greater than 20 dB in the case of single
  diffraction (i.e. thin barriers) and 25 dB in the case of multiple diffraction (with e > 0)."*
  Exact same wording/values as 1996. **Not yet re-added to `barrierAttenuation.m`** after being
  removed pending this confirmation — should be restored.

## Clause 7.5 Reflections — fuller read (single flat-surface + multi-reflection + cylindrical)

- **7.5.1 General**: unchanged in substance from 1996 (image sources; ground reflection excluded,
  already inside Agr).
- **7.5.2 Single reflection at a flat surface**: surface-size validity criterion reworked —
  eq.(26): `1/lambda > [2/leff²] * [dS,O*dO,R / (dS,O+dO,R)]`, with eq.(27):
  `leff = min(a*cos(beta_a), h*cos(beta_h))` — `a`/`h` = horizontal/vertical extension of the
  reflecting surface, `beta_a`/`beta_h` = angle of incidence projected onto the horizontal / onto
  a vertical plane normal to the surface, respectively. (1996 used a single `lmin` = min surface
  dimension; 2024's `leff` separately weights the horizontal and vertical extents by their own
  incidence-angle projections — more precise, not just relabeled.) If the criterion fails for a
  band, neglect that band's reflection.
  - Eq.(28): `Lw,im = Lw + 10*lg(1-alpha) + D_Ir` dB — image-source sound power level. Uses
    **absorption coefficient alpha** (not reflection coefficient rho as in 1996's eq.20 — physically
    rho≈1-alpha, so this is the same idea reparameterized). **Default alpha=0.1** for building
    facades / industrial-facility surfaces when no data available (vs. 1996's Table 4 rho-by-
    object-type lookup, which is dropped from the 2024 main text — no equivalent table found in
    the pages reviewed for flat surfaces, only for cylinders, see below).
- **7.5.3 Multi-reflection up to higher orders — new in 2024** (1996 only handled single
  reflection): the nth-order image source is the image of the (n-1)th-order image. Eq.(26)/(27)
  validity criterion re-checked per reflector, using the (possibly bent) total path lengths
  dS,O/dO,R to/from each reflector. Eq.(29): `Lw,im,N = Lw + 10*lg[prod_n(1-alpha_n)] + D_Ir` —
  product of `(1-alpha_n)` across all N reflection points.
- **7.5.4 Reflections at cylindrical surfaces**: intro text mostly points to Reference [13] for
  derivation, but the operational formula is the eq.(30) `A_curv` already transcribed in the first
  pass of this review (see the Clause 7.3/barrier sections above — unchanged from that read, just
  confirming it belongs here structurally, not misplaced).

None of clause 7.5 (single/multi-order reflections, or the cylindrical A_curv term) is yet
implemented in `matlab/+noiseanalyzer/`.

For reference, the cylindrical-surface formula (eq.30, first transcribed in the initial pass):
`A_curv = 10*lg[1 + (2*dS*dR)/(r*(dS+dR)) * (1-k²)^(-1/2)]` dB, `k = d/r` — dS/dR =
source/receiver-to-reflection-point distances, r = cylinder radius, d = perpendicular distance of
the incident ray's line from the cylinder's centre. Applied as part of Amisc.

## Clause 8 Meteorological correction — unchanged

2024 eq.31/32 are identical to 1996 eq.21/22 (`Cmet=0` if `dp<=10(hS+hR)`, else
`Cmet=C0*[1-10(hS+hR)/dp]`). No change.

## Annex D (informative) — Calculation of sound pressure levels caused by wind turbines

New in 2024, and the most likely directly-relevant addition given the project's origin (a PUC
electric-utility docket exhibit). Full text read (D.1-D.7, short — about 3 pages):

- **D.1 Applicability**: land-based and near-shore wind turbines; years of comparison against
  measurements back the method **with the modifications below** (not the base method as-is).
- **D.2 Source modelling**: apparent sound power per IEC 61400-11; modelled as an **omnidirectional
  point source at hub height H** (rotor centre for vertical-axis turbines).
- **D.3 Barrier attenuation caution**: reported cases where standard Abar (clause 7.4) didn't match
  observed barrier effects for wind turbines. Recommends either using a source height *higher*
  than hub height (e.g. blade-tip height) and/or **capping Abar at 3 dB** for terrain screening.
  Explicitly doesn't cover building screening, only terrain.
- **D.4 Ground attenuation — important deviation**: using G=1 (full porous, e.g. grass/farmland)
  per the base 7.3.1 classification **under-predicts** measured wind-turbine levels and "should
  therefore not be applied." Recommendation: **hard ground G=0 as normal; porous/mixed ground
  capped at a maximum of G=0.5** (not 1). When G=0.5 is used, recommends a minimum receiver height
  of 4 m regardless of actual height.
- **D.5 Concave ground-profile correction**: new empirical correction `dAgr = -3 dB` (eq.D.1),
  added to Agr, applied across all octave bands when propagation crosses a valley such that the
  mean propagation height hm is at least 50% higher than it would be over flat ground:
  `hm >= 1.5*(hS+hR)/2` (eq.D.2). Explicitly flagged as a "temporary convention," indicative only.
- **D.6 Meteorological correction**: standard clause 8 approach applies; additionally notes that
  for long-term averages, wind-speed-dependent variation in emitted sound power must be accounted
  for (turbines are louder at higher wind speeds up to rated power).
- **D.7 Uncertainty**: cites that neither the wind-speed range (clause 5) nor height range
  (Table 4) restrict applicability to turbines. Consensus from multiple studies: **G=0 with a
  positive source-level uncertainty margin tends to overstate** measured levels, while **G=0.5
  with no positive adjustment tends to understate** them — i.e. the true answer is bracketed
  between those two modelling choices, not nailed down by the standard itself.

## Clause 9 Accuracy and limitations — unchanged

Table 4 (2024) = Table 5 (1996), identical values: ±3 dB for 0-5m mean height at any distance up
to 1000m; ±1 dB for 5-30m height at 0-100m, ±3 dB at 100-1000m. No estimate beyond 1000m. 2024
adds a footnote: the "30m" height ceiling was from 1996-era experience, but the same uncertainty
figures have since been shown (informally) to extend to sources up to ~200m — chimney stacks,
wind turbines — see Annex D.

## Annex A (informative) — Additional types of attenuation, Amisc

- **A.2 Foliage (Afol)**: Table A.1 is **byte-for-byte identical** to 1996 Table A.1 (same dB and
  dB/m values per band, same 10-20m/20-200m/>200m breakpoints). Unchanged.
  - **A.2.3 New**: an optional "detailed method using forestal parameters" (Klin = G0 + GD·D +
    GG·G + GV·V + GS·S + GZ·Z, eq.A.3, with per-band weighting factors in Table A.4, applied as
    Afol = Klin·df/1000 by analogy with the atmospheric-absorption pattern — this scaling wasn't
    stated explicitly on the page read, inferred from the dB/km units of Klin and Table A.4;
    verify before relying on it). Requires forestry survey data (stem diameter, basal area,
    standing stock, structuring/foliage classification) not normally available — described as an
    alternative to the simple Table A.1 method for expert-level work, referencing external sources
    [14][15] for the underlying method. Not implemented — narrow applicability, needs real forestry
    data as input.
- **A.3 Industrial sites (Asite)**: Table A.7 **byte-for-byte identical** to 1996 Table A.2 (same
  dB/m per band), same 10 dB cap. Unchanged.
- **A.4 Housing (Ahous)**: **simplified vs. 1996** — eq.(A.4): `Ahous = Ahous,1 + Ahous,2`,
  eq.(A.5): `Ahous,1 = 0.1*B*db` dB (B = building plan-area density, db = path length through the
  built-up region) — same as 1996's Ahous,1 formula. **No explicit formula for Ahous,2 was found**
  on the pages read (1996 had eq.A.3 for "well-defined rows of buildings," `Ahous,2 =
  -10*lg[1-(p/100)]`); the 2024 text moves directly from eq.(A.5) to discussing db and the
  zero-out condition for a clear sight-line corridor, without introducing an eq. for Ahous,2. Cap
  at 10 dB total, still stated. Possibly Ahous,2 was dropped in 2024, or its formula is on a page
  not captured in this review — flagged as unresolved, not confirmed either way.

## Annex B (informative) — Directivity correction, Dc, for chimney stacks — new in 2024

Models a chimney/vertical open-pipe source as a point source at the opening centre, with an
empirically-derived directivity correction depending on radiation angle and a dimensionless `ka`
(wavenumber × opening radius) parameter:

- Eq.(B.1): `theta = 180° - arctan(dp/(hS-hR)) - arcsin(d/(2r))` — the downwind-curved-ray
  radiation angle (theta=0 is straight up), r = 5000m fixed curvature radius.
- Eq.(B.2): `delta_theta = arcsin(d/(2r))` — the curvature correction term embedded in eq.(B.1);
  applies whenever the calculated receiver level should represent downwind conditions.
- Eq.(B.3): `ka = 2*pi*a*f / [331.4*sqrt(1+T/273°C)]` — a = chimney-opening radius (m), f =
  octave-band nominal frequency (Hz), T = temperature at the chimney mouth (°C).
- **Table B.1**: Dc (dB) tabulated for theta in {30,45,60,75,90,105,120}° × ka in
  {4.0,5.0,6.3,8.0,10.1,12.7,16.0,20.2,25.4,32.0} — 2D table, interpolate between grid points.
  *(One value, theta=120°/ka=6.3, reads "-77" in the source — almost certainly a typo for "-7.7"
  given neighbouring values are -7.0 (ka=5.0) and -8.2 (ka=8.0); not re-verified against the raw
  PDF pixel-by-pixel, flag if this matters.)*
  - Extension rules: ka<1 → Dc=0; 1≤ka≤4 → interpolate down to the ka=4 row; ka>32 → hold at the
    ka=32 column; theta<30° → hold at the theta=30° row; theta>120° → hold at the theta=120° row.
- Not implemented in `matlab/+noiseanalyzer/` yet — needs 2D interpolation (e.g. `interp2`) over
  Table B.1 plus the extension/clamping rules; narrower applicability (chimney/vertical-pipe
  sources specifically) than the rest of the module, lower priority unless directly needed.

## Annex C (informative) — Meteorological correction from angular wind distribution — new in 2024

An alternative way to derive C0 (used in eq.31/32) directly from local wind-climatology data
instead of the "elementary statistics" estimate in clause 8:

- Eq.(C.1): `C0(phi') = 10*lg[ integral_0^2pi p'wd(phi'+phi) * 10^(Dwd(2pi-phi)/10) dphi ]` dB —
  phi' = propagation direction (source→receiver, meteorological convention: 0=north, clockwise),
  p'wd(phi) = wind-rose relative frequency from direction phi, Dwd(delta) = apparent large-distance
  directivity when wind blows from delta=0.
- Eq.(C.2) (an example/default model for Dwd): `Dwd(phi) = -Q*{1 - cos[phi - pi - phi_w*sin(phi-pi)]}`
  dB *(transcribed as `phi_w` here for the angle-width parameter to avoid clashing with the outer
  `phi` — the standard reuses the symbol `phi` for both the integration variable and this width
  parameter; written as `φ` for both in the original, disambiguate carefully if implementing)*,
  where Q = half the upwind large-distance attenuation (dB), and the width parameter = angle
  defining the upwind attenuation window. **Preferred/default values per the standard: Q=5 dB,
  width=pi/4.**
- Eq.(C.3)/(C.4): discretizing into N angle bins of width `Δphi=2*pi/N`, bin-center
  `phi_n=(n-1/2)*Δphi`.
- Eq.(C.5): discretized form of eq.(C.1) as a sum over wind-rose bins `pwd(phi)`.
- Eq.(C.6) (avoids needing a pre-binned wind rose — sum directly over raw wind-direction samples):
  `C0(phi_m) = -10*lg{ (1/N) * sum_n[ 10^(0.1*Dwd(phi_n - phi_m)) ] }` dB, phi_m = source→receiver
  direction, phi_n = each sample's recorded wind direction, N = number of samples in the reference/
  long-term interval.
- C.2 gives a worked example using a real wind dataset (Table C.1, excerpted hourly data) —
  illustrative only, no new formulas.
- **Implementable without external data**: eq.(C.2) [`Dwd`] and eq.(C.6) [`C0` from raw samples]
  are both self-contained given wind-direction sample data as input (the user's own measurements),
  unlike Annex B which needs the fixed Table B.1. Reasonable candidate for implementation.
